# Посты с фото — стиль «Кинокадр»

Фирменный стиль Л5 Калуга для постов с фотографиями: фото на весь кадр (1620×1080),
золотая рамка, эмблема Л5 слева сверху, тёмный градиент снизу с заголовком и слоганом.

## Как сделать новый пост
1. Положите фото в `assets/` (горизонтальное, лучше 3:2).
2. Добавьте запись в `posts.json`:
   ```json
   {"out": "out/имя.png", "photo": "assets/фото.jpg",
    "kicker": "Подпись сверху", "title": "БЕЛАЯ ЧАСТЬ", "gold": "ЗОЛОТАЯ"}
   ```
   Необязательно: `"position": "50% 30%"` — сдвинуть кадр, если фото не 3:2.
3. Запустите `node make.js` (нужен Playwright). Готовые картинки — в `out/`.

Длинный заголовок автоматически уменьшается, чтобы не наезжать на слоган.

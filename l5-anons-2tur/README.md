# Анонс матча — 2 тур (Л5 Калуга — Кондрово)

Карточка 1080×1349 повторяет оформление карточки «1 ТУР» группы
(размеры, отступы, цвета и начертания сняты с оригинала по пикселям).

Новый анонс: скопируйте `source/tur2.json`, поменяйте номер тура (`N`), гербы, названия
и строки, затем `cd source && node anons2.js tur3.json`.
Для двузначного номера или другой цифры сдвиньте `TX` так, чтобы зазор до «ТУР» был ~71 px.

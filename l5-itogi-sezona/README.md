# Л5 Калуга — итоги сезона 2026

Две карточки 1080×1350 на фирменном шаблоне группы:

- `L5_itogi_sezona_1.png` — «Итоги 2026», общее фото с кубком и дипломом
- `L5_itogi_sezona_2.png` — «Личные награды», фото со статуэтками

Исходники в `source/`: `card.html` — макет, `render.js` — тексты карточек и рендер.
Поменять текст: правьте массив `cards` в `render.js`, затем
`cd source && node render.js` (нужен Playwright).

Две карточки 1080×1350 на фирменном шаблоне группы:

- `L5_itogi_sezona_1.png` — «1 место»: кубок, медали, диплом; 10 ноября, Областной молодёжный центр
- `L5_itogi_sezona_2.png` — «Лучшие игроки»: Иван Родин, Вячеслав Думбрава

Поменять текст: правьте массив `cards` в `render.js`, затем
`cd source && node render.js` (нужен Playwright).

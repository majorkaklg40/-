# Live Photo — IMG_4080

Пара файлов Live Photo, собранная из `IMG_4080.mp4`:

- `IMG_4080.JPG` — ключевой кадр (2.0 с), Apple MakerNote `ContentIdentifier`
- `IMG_4080.MOV` — видео 4.96 с, `com.apple.quicktime.content.identifier` + дорожка `still-image-time`

Content Identifier: `6666BB97-9892-4CBB-A799-36BD234F0FC2`

Импортируйте **оба файла вместе** (например, в Фото на Mac или AirDrop обоих на iPhone),
чтобы они склеились в одно Live Photo.

Пересобрать: `python3 make_live.py <video.mp4> <out_dir> <секунда_кадра>` (нужны ffmpeg, exiftool, Pillow).
